# MoltiCar

A web application for managing car dealership operations, built for Iranian 
car showrooms to replace manual/paper-based inventory tracking with a modern, 
role-based system.

## Features
- 📋 Vehicle inventory management with image galleries (Alpine.js lightbox)
- 👥 Employee management with granular role-based authorization (Gates/Policies)
- ✅ Soft-delete workflow with manager approval
- 🔍 Sortable, paginated listings

## Tech Stack
- Laravel
- Livewire
- Tailwind CSS
- Alpine.js
- PHPStan (static analysis)
